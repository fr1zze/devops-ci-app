# devops-ci-app

Учебное Flask-приложение для практической работы №10.

## HTTP-интерфейс

- `/` — сведения о службе: название, версия и статус.
- `/health` — проверка жизнеспособности: {"status": "ok"}.

## Проверки и публикация

GitHub Actions выполняет статический анализ Pylint, тесты pytest,
сборку Docker-образа и smoke-test контейнера.

После успешных проверок в main образ публикуется в GHCR
с тегами полного SHA коммита и latest.
Для Pull Request публикация не выполняется.
