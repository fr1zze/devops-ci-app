# Сведения для развёртывания

## Виртуальная машина

- Имя: devops-vm.
- Пользователь SSH: devops.
- Адрес VM в сети 192.168.56.0/24: 192.168.56.101.
- Другой адрес VM: 10.0.2.15.
- Адрес и порт SSH перед автоматизацией необходимо проверить
  с компьютера, на котором будет запускаться Ansible.

## Docker-образ

- Реестр: GitHub Container Registry.
- Образ: ghcr.io/fr1zze/devops-ci-app.
- Проверенный тег SHA: af8603851aaf2b65992c831c5f84e3239bfb31e1.
- Пакет публичный: для загрузки аутентификация не требуется.
- Порт приложения внутри контейнера: 5000.
- Проверка состояния: GET /health.
- Ожидаемый ответ: HTTP 200 и {"status":"ok"}.
- Пользователь контейнера: app, UID 999.

## Проверка на VM

Образ проверен с тегами latest и полного SHA.
Для latest использован адрес http://127.0.0.1:5001/health.
Для SHA использован адрес http://127.0.0.1:5002/health.
Обе проверки вернули {"status":"ok"}.

## Будущее развёртывание через Ansible

Использовать образ с указанным полным SHA.
Перед запуском выбрать свободный порт на VM.

Ansible должен загружать готовый образ из GHCR:
этот образ уже собран и проверен CI.
Повторная сборка на VM может дать другой результат
и требует установки инструментов сборки на сервер.
